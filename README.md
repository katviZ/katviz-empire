# KatViz Empire

The home base for **Katviz** — AI-powered 3D visuals and automation.

> *Light, bent to your will.*

## Structure

| Folder | What's inside |
|---|---|
| `brand-kit/` | Logo set, design tokens, brand guidelines, and a live style-guide page (`index.html`). |
| `site/` | The Katviz landing page — single-file WebGL site, no build step. |

## Brand kit

- **Logos** — `brand-kit/logo/` (primary mark, social avatar, favicon)
- **Tokens** — `brand-kit/tokens.css` (drop into any project)
- **Guidelines** — `brand-kit/BRAND.md`
- **Showcase** — open `brand-kit/index.html` in a browser

Brand system: **Prism Noir v2.0** — AI-lab luxury. A white beam enters the prism; a spectrum leaves. *Light, bent to your will.*

## Site

`site/index.html` is the whole site — deployed via GitHub Pages to
**https://katviz.github.io/katviz-empire/**.
